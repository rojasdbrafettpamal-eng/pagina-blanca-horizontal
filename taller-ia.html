Cómo funciona
La app mantiene abierto el proyecto; el agente trabaja en el repositorio compartido.
Flujo para trabajar con una IA
1. Crea el proyecto y crea una primera versión de tu juego. 2. Conecta un repositorio público de GitHub. 3. Copia las instrucciones y compártelas con el agente junto con la tarea. 4. Pídele que guarde sus cambios en el mismo repositorio. 5. Vuelve aquí y pulsa “Actualizar del repositorio”; abre “Probar juego” para revisar el resultado.
Limitación importante de esta primera versión: no enlaza automáticamente con la cuenta ni la API de Claude o Grok, no sube cambios a GitHub y no puede conectarse a repositorios privados. La conexión permite leer repositorios públicos; para una sincronización automática y privada hará falta implementar un inicio de sesión seguro y las integraciones correspondientes.
